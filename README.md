## 🕹️ Overview

WED (World Editor) is the official X-Plane scenery authoring tool for creating airport layouts, taxiways, ground textures, and ATC flow configurations.

Whether you're a newcomer or a veteran, X-Plane WED provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Airport Layout** | Draw runways, taxiways, aprons, and parking positions |
| **ATC Flow Config** | Define departure and arrival flows for ATC in X-Plane 12 |
| **Object Placement** | Place and rotate library objects and custom 3D models |
| **Gateway Export** | Submit finished airports to the X-Plane Airport Gateway |
